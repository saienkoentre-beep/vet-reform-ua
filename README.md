# Реформа професійної освіти в Україні

Незалежний багатосторінковий інформаційний сайт про реформу професійної (професійно-технічної) освіти в Україні.

## Структура

- `index.html` — головна сторінка
- `pro-reformu.html` — суть реформи, напрями, етапи впровадження
- `normatyvna-baza.html` — нормативна база з посиланнями на офіційні джерела
- `novyny.html` — ключові події реформи
- `kontakty.html` — контакти
- `css/style.css` — спільні стилі

## Технології

Статичний сайт на чистому HTML/CSS, без збірки та залежностей — можна розгортати на GitHub Pages чи будь-якому статичному хостингу.

## Розгортання на GitHub Pages

1. Settings → Pages
2. Source: **Deploy from a branch**
3. Branch: `main`, папка `/ (root)`
4. Save

Сайт стане доступним за адресою `https://saienkoentre-beep.github.io/vet-reform-ua/`.
